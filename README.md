# Stockwise

*Demand forecasting that tells you how much to order, not just what to
expect.*

Retail demand forecasting on the M5 dataset (30,490 item-store series,
intermittent demand, hierarchy) with four dependent layers:

```
Forecast  ->  Uncertainty  ->  Decision  ->  Explanation
```

Quantile forecasts (P10-P90) calibrated with conformal prediction, fed into
a newsvendor decision layer for a recommended order quantity, explained in
plain language grounded in the model's own SHAP attributions.

> **Status: work in progress.** This README covers what's built so far.
> The full write-up (architecture diagram, final results table, live
> demo link) lands at project completion — see `DEVLOG.md` for a running
> log of decisions and bugs fixed along the way.

## What's done

- **Data pipeline** — ingest, feature engineering (40 columns: lags,
  rolling windows, price/event/calendar features, intermittency stats),
  and scenario overrides for live serving. Leakage-tested: no feature
  reads sales data newer than `t - 28`.
- **Baselines + metrics** — naive, seasonal-naive, moving-average
  baselines; WRMSSE (the official M5 metric), pinball loss, and coverage
  calculation.

Everything else (point/quantile models, conformal calibration, the
newsvendor decision layer, the explanation layer, the API, and the
dashboard) is still ahead.

## Setup

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements-features.txt   # pandas, pyarrow, numpy, pytest
pip install -r requirements.txt            # + serving deps (fastapi, lightgbm, shap, ...)
```

Run the tests:

```bash
python -m pytest tests/ -v
```

## Data

Sourced from the [M5 Forecasting Accuracy](https://www.kaggle.com/competitions/m5-forecasting-accuracy)
competition (Walmart, via Kaggle). The full 10-store reshape/merge/feature
pipeline runs in Colab (`notebooks/01_build_features.ipynb`) since the
59.2M-row long-format dataset doesn't fit in 8GB of local RAM; a single
store's feature sample (`data/ca1_features.parquet`, generated by that
notebook, not committed — see `.gitignore`) is used for local iteration.
